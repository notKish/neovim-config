==============================================================================
1. INTRO                                        *fundamentals-intro*

Fundamentals is a learning plugin that demonstrates core Neovim API concepts
like keymaps, autocommands, buffer manipulation, and external commands.

==============================================================================
2. SETUP                                        *fundamentals-setup*

To enable the plugin, call the setup function in your init.lua: >lua

    require('fundamentals').setup({
      greeting = "Hello World",
      show_timestamp = true,
      auto_welcome_lua = true,
    })
<

==============================================================================
3. COMMANDS                                     *fundamentals-commands*

There are no custom commands in this version, but you can use :r! to 
insert git logs: >vim

    :r! git log -1 --format="\%h - \%s"
<

==============================================================================
4. MAPPINGS                                     *fundamentals-mappings*

The following mappings are created by default:

Key             Mode    Description~
<leader>fg      Normal  Print the configured greeting message.
<leader>fc      Normal  Insert a line count header at the top of the buffer.
<leader>gl      Normal  Show the last git commit message in the command line.
